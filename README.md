# rift-view/homebrew-tap

Homebrew tap for [Terminus](https://github.com/juliushamm/terminus) and other rift-view tools.

## Install

```bash
brew install --cask rift-view/tap/terminus
```

Or, for repeated use:

```bash
brew tap rift-view/tap
brew install --cask terminus
```

## Available casks

| Cask | Description |
|---|---|
| `terminus` | Visual AWS infrastructure management |
