# rift-view/homebrew-tap

Homebrew tap for [RiftView](https://github.com/rift-view/riftview) and other rift-view tools.

## Install

```bash
brew install --cask rift-view/tap/riftview
```

Or, for repeated use:

```bash
brew tap rift-view/tap
brew install --cask riftview
```

## Available casks

| Cask | Description |
|---|---|
| `riftview` | Visual AWS infrastructure management |
